Chạy run-local.cmd, mở http://localhost:8080/login.html. Đăng nhập uc09_local_giaovu hoặc uc09_local_bgh, mật khẩu demo Test@12345. Có trang chủ/dashboard, hồ sơ và tìm kiếm học sinh, người giám hộ, giáo viên, lớp học và xếp/chuyển lớp.
